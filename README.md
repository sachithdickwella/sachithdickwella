## 👋 Introduction

Welcome to my GitHub space. I build intelligent systems that fuse software engineering, robotics, AI, and aerospace technology.  
My current focus is on designing next-generation autonomous fixed-wing UAVs — developing the full autonomy stack including simulation (UE5), digital-twin modelling, AI-driven flight control, and embedded deployment.

I work across an intersection of disciplines: distributed microservices, computer vision, control theory, aerodynamics, and high-performance backend engineering.

---

## 🔧 What I Work On

- **Autonomous UAV Systems:** AI-first control loops (PID + RL hybrids), ONNX-based inference, modular avionics, and real-world prototyping.
- **Simulation & Robotics:** UE5, Omniverse-style workflows, physics-accurate digital twins, multi-agent behaviour modelling.
- **Software Engineering:** Java, C++, Python, Kotlin, Spring Cloud, microservices, event-driven backends, RabbitMQ, Kafka.
- **AI & CV:** Custom object detection/segmentation, anchor-free models, data pipelines, model conversion and optimisation (ONNX, TorchScript).
