## 👋 Introduction

Welcome to my GitHub space. I build intelligent systems that fuse robotics, AI, software engineering, and aerospace technology.  

My current focus is designing next-generation **autonomous fixed-wing UAVs**:  
digital-twin simulation (UE5), AI flight-control pipelines, embedded inference, and end-to-end autonomy R&D.

My work spans distributed microservices, computer vision, control theory, aerodynamics, and high-performance backend engineering.

---

## 🔧 What I Work On

- **UAV Autonomy:** PID + RL hybrid control loops, ONNX-based inference, modular avionics architecture  
- **Simulation & Robotics:** UE5 environments, physics-accurate digital twins, multi-agent control  
- **Software Engineering:** Java, Kotlin, C++, Python, Spring Cloud, microservices, Kafka, RabbitMQ  
- **AI & Computer Vision:** Custom detectors, anchor-free architectures, segmentation, model optimisation

## 🎓 Academic Track
